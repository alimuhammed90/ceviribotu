# ceviribotu

Bu kodlarda, Python programlama dili ile birlikte Discord.py kütüphanesi kullanılmıştır. Kodun temel amacı, Discord sunucusunda kullanıcı tarafından yazılan Türkçe bir cümleyi veya kelimeyi İngilizceye çevirmektir. Bunun için `translate` kütüphanesinden yararlanılmıştır.

Kullanıcı Discord üzerinde belirlenen komutu kullandığında, bot girilen Türkçe metni alır ve çeviri işlemini gerçekleştirir. Ardından elde edilen İngilizce çeviriyi tekrar Discord kanalına gönderir. Böylece kullanıcılar herhangi bir ek uygulamaya ihtiyaç duymadan Discord üzerinden hızlı ve kolay bir şekilde çeviri yapabilir.

Kod içerisinde Discord botunun çalışmasını sağlayan Discord.py yapısı ile çeviri işlemini gerçekleştiren `translate` kütüphanesi birlikte kullanılmıştır. Bu sayede bot, hem Discord ile iletişim kurabilir hem de verilen metinleri Türkçeden İngilizceye çevirebilir.
